# netzip-fullpull documentation authority

This directory is the single authority for protocol behavior shared by
`quoteNetzipRs`, `netzip_win`, `tdxRs`, `netzip-supplement`, and
`stock-source-netzip`.

- `STATUS.md`: current gaps and gate state.
- `PROTOCOL.md`: promoted protocol and decoder rules.
- `EXPERIENCE.md`: reusable operational lessons and known traps.
- `EVIDENCE_INDEX.md`: immutable evidence locations and hashes.
- `HYPOTHESES.md`: open and rejected explanations.
- `ACCEPTANCE.md`: promotion and consumer verification gates.
- `GITHUB_RELEASE.md`: repository, consumer, and GitHub update procedure.

Product-specific runtime, UI, API, deployment, and rollback details remain in
the consuming project. Project progress logs are execution journals and are
not protocol authority.
